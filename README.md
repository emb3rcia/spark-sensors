# About project
spark-sensors is simple TUI app written in Python and inspired by lm-sensors. It provides data from every sensor exposed under hwmon linux directory.

## Motivation for the project
I wanted to make something fairly simple when returning to coding after a break, as well as reinforce my skills in `Textual`

## Learning outcomes
I reinforced my skills in `Textual`

# Project status
Project reached all requirements for 0.1.0 release.

## Planned features

# Dependencies
- `textual`

Install with pip: 

`pip install textual rich`

Install command for Arch-based distributions:

`sudo pacman -S python-textual`
